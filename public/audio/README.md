# Sound audio files

Place licensed, original, public-domain, or CC0 MP3 files here:

- `rain.mp3`
- `ocean.mp3`
- `fireplace.mp3`
- `forest.mp3`
- `thunderstorm.mp3`
- `brown-noise.mp3`
- `pink-noise.mp3`
- `cafe-ambience.mp3`

The Sounds page references these paths from `src/data/sounds.ts`. If a file is missing, the page still loads and shows a non-blocking error when playback is attempted.

Do not commit copyrighted audio without proper licensing.
